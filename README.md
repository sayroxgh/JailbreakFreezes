# CS2 Jailbreak Freeze System

A CounterStrikeSharp plugin for Counter-Strike 2 Jailbreak servers.

## Features
- Freeze all Terrorist players
- Unfreeze all Terrorist players
- Countdown freeze system
- HUD countdown display
- Freeze sound effects
- Glow effects for frozen players

## Commands
- `css_fz <seconds>` → Start freeze countdown 
- `css_fz0` → Cancel freeze countdown 
- `css_td` → Freeze all Terrorists 
- `css_tdb` → Unfreeze all Terrorists 

## Requirements
- Metamod
- CounterStrikeSharp
- CS2 Dedicated Server
